# Eternal Kingdoms - Base de diseño + prototipo

Este repositorio incluye:
- `GDD.md`: documento de diseño completo del videojuego solicitado.
- `prototype/`: prototipo jugable local en HTML/CSS/JS.

## Ya empezamos a programar la primera tarea
Se implementó la **primera misión principal jugable**:
- "Limpia el Camino del Molino"
- Objetivo: derrotar 3 enemigos de rango D.
- Después puedes entregar la misión para recibir recompensa (XP y oro).

## ¿Dónde pego el código para probarlo?
No necesitas pegarlo en otro sitio: **ya está guardado en archivos del proyecto**.

Ejecuta estos pasos:

```bash
cd /workspace/papucho
python3 -m http.server 8000
```

Luego abre en tu navegador:
- `http://localhost:8000/prototype/`
